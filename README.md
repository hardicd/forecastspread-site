# forecastspread-site

The website for ForecastSpread, a pixel-art weather app for iPhone and Apple Watch, served by GitHub Pages at https://hardicd.github.io/forecastspread-site/.

- `index.html`: landing page. Set `TESTFLIGHT_URL` near the bottom once the public beta link exists.
- `privacy/` and `support/`: built from the drafts in the project's legal folder; keep them in step with the in-app Privacy Policy.
